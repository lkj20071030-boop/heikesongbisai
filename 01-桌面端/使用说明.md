# 智析 AI · Windows 教学工作台

版本 1.0.0 · 2026-11-06

面向大中小学教师的一站式教学方案工作台：教师先声明身份、学段、学科、教材版本，平台把教材、课标、解读、校本资料组织成一张可追溯的知识图谱，再根据一句教学需求生成结构化方案。保留学生学习诊断模式，首次启动时双入口选择身份。

当前版本使用内置课程知识库，全部计算在本机完成；配置 OpenAI 兼容 API Key 后可调用外部模型，未配置时自动使用本地知识引擎。

---

## 1. 启动

正式客户端：

```
发布\智析AI.exe
```

演示控制台（独立程序，内置 9 幕学习诊断演示 + JSON 脚本驱动）：

```
发布\智析AI-演示控制台.exe
```

两个 exe 共用前端资源，但窗口、图标、数据目录完全独立，可同时运行。无需安装。

系统要求：

- Windows 10 / 11（64 位）
- .NET Framework 4.6.2 及以上（Windows 10/11 自带 4.8）
- Microsoft Edge WebView2 Runtime（绝大多数 Windows 10/11 已内置；缺失时程序会给出下载地址）

SmartScreen 提示「未知发布者」时，选择「更多信息 → 仍要运行」。本版本未做代码签名。

---

## 2. 首次启动：选择身份

首次启动进入三步引导，不会直接进入工作台：

1. **身份**：教师 / 学生。必须选择，决定侧栏、默认页与工作台形态。
2. **学段 / 学科 / 教材**：教师需选择教材版本（如人教版、北师大版、教科版）；学生只需学段与学科。
3. **模型连接（可跳过）**：OpenAI 兼容服务商、Base URL、API Key、模型名。跳过则使用本地知识引擎。

完成后：

- 教师进入「教师工作台」，侧栏：工作台、我的方案、知识图谱、资料库、班级与学情、设置。
- 学生进入「工作台」，侧栏：工作台、知识诊断、知识图谱、学习路径、探索记录、设置。

身份切换只放在「设置 → 使用身份」，切换后侧栏与默认页同步变化，已保存的方案与记录不会丢失。

## 3. 教师工作台

工作台按五步组织：**选课程 → 说需求 → 生成方案 → 核对依据 → 保存/复盘**。顶部步骤条会高亮当前步骤，并在下方给出下一步提示。

三栏布局：

### 左栏 · 需求

- 需求描述：例如「把牛顿第二定律上成一节 40 分钟的新授课，学生基础中等，实验室不可用」。
- 方案类型、时长、约束会随学段变化：
  - 小学 / 初中 / 高中：新授 / 复习 / 实验 / 单元 / 项目 / 分层；40 / 45 / 90 分钟；无实验器材 / 只有投影 / 大班额 / 需要分层作业。
  - 大学：讲授 / 研讨 / 实验 / 上机 / 课程大纲 / 复习；45 / 90 / 120 分钟；无助教 / 机房不足 / 大班额 / 双语教学 / 课程思政 / 需要阅读材料。
- **快速备课**默认只显示需求、课型、时长；学情与约束折叠在「更多设置」，不打断日常备课。
- 生成按钮与当前引擎状态。

### 中栏 · 方案

生成过程分四步：检索资料 → 构建图谱 → 生成方案 → 质量检查。

配置模型 Key 后，「生成方案」内部由分环节 Agent 执行：生成方案骨架 → 生成完整方案 → 质量检查 → 按质检修订。每个环节独立提示词、JSON 校验、修复重试；任一步失败会回退本地规则，不会阻断生成。方案页会显示「Agent 运行轨迹」卡片，标注每个环节的引擎（模型/本地）、状态与耗时；未配置 Key 时也会显示本地规则轨迹。

生成后得到结构化方案：

- 学习目标 / 课程目标（带来源）
- 重难点
- 前概念与易错点
- 教学流程时间轴：
  - K12：导入 / 探究 / 建构 / 应用 / 总结，5 段。
  - 大学：问题导入 / 概念讲授 / 推导或证明 / 案例应用 / 小组讨论 / 课堂练习 / 总结与作业，7 段，共 90 分钟。
- 评价证据
- 分层作业：K12 为基础 / 提高 / 补偿；大学为 Problem Set / Project / Reading。
- 风险与替代方案
- 大学方案头额外显示：课程代码、学分、学时、授课对象、考核方式。

方案支持：

- **保存**：写入「我的方案」，再次保存会追加版本，不覆盖旧版。
- **导出 Markdown**：保存到 `Documents\智析AI\导出\`；大学导出包含课程信息、阅读材料与学术诚信说明。
- **微调**：更基础 / 更挑战 / 压缩到当前学段的压缩时长（K12 40 分钟，大学 60 分钟）/ 增加动手或实践环节。
- **重新生成**：按当前需求重新跑一遍。

方案的阅读顺序是固定的：

```
封面（是什么课/给谁上）
→ 概览（本课要解决 + 目标/流程/来源/质检 4 个数字）
→ 方案目录（01–05，可点击跳转）
→ 01 目标
→ 02 学情与重难点
→ 03 教学流程（主体）
→ 04 评价与作业
→ 05 分层与风险（默认折叠）
→ 调整方案（默认折叠）
→ 底部收口（保存/导出/去我的方案）
```

如果改了教师档案（学段/学科）但当前打开的是旧方案，工作台会提示「教师档案已变更」，点「新建方案」即可按新档案选择场景。

### 右栏 · 依据

- 知识图谱缩略图：节点可点，显示概念、层级与来源。
- 资料源：教材 / 课标或大纲 / 解读 / 校本 / 外部 / 论文，含位置、可信度、引用次数。
- 质量检查：
  - K12：目标来源覆盖、课标对齐、时间预算、易错点覆盖、活动多样性（5 项）。
  - 大学：目标来源覆盖、大纲对齐、学时匹配、易错点覆盖、考核对应、阅读量、学术诚信（7 项）。
- 班级学情：示例班级的共性断点 Top 3。

### 其他教师页面

- **我的方案**：方案列表、搜索、版本数、课程代码/学分（大学）、打开、导出、删除。
- **知识图谱**：图谱放大模式，左侧大图、右侧节点详情与来源。
- **资料库**：6 个教学场景的内置资料 + 用户添加的文本资料；支持搜索、类型筛选、`.txt/.md/.json` 读取与粘贴文本。
- **班级与学情**：示例班级、样本量、学期、>40% 共性断点与趋势，可导出 Markdown。

当前内置 6 个教学场景：

**K12**

1. 小学科学 · 简单电路（教科版六年级上册）
2. 初中数学 · 一次函数（北师大版八年级上册）
3. 高中物理 · 牛顿第二定律（人教版必修一）

**大学**

4. 大学数学 · 高等数学（同济版）· 导数概念（MATH101，4 学分，90 分钟讲授）
5. 大学物理 · 大学物理（马文蔚版）· 牛顿运动定律（PHYS101，4 学分，90 分钟讲授 + 演示实验）
6. 大学计算机 · 计算机科学导论（自编讲义）· 递归（CS101，3 学分，90 分钟讲授 + 上机）

**大学学科支持自定义**：在首次引导或设置里直接填写学科（如医学统计学、专业英语）。如果该学科没有内置场景，平台会使用「大学通用结构模板」，并明确提示来源待补充；补充教材/大纲后再生成，依据会更准确。它不会伪造学科内容。

## 4. 大模型 API 接入

「设置 → 模型连接」支持完整 OpenAI 兼容接口：

- 服务商预设：OpenAI / DeepSeek / 智谱 / 通义 / 自定义。
- Base URL、API Key、模型名、温度。
- 测试连接：发送一条「只回复 OK」的消息。
- 未配置 Key：显示「本地知识引擎」，方案仍可生成。
- 已配置 Key：显示「已连接 · 模型名」，生成方案时优先调用模型；失败或超时会自动回退本地引擎，并在方案头标注生成来源。
- Agent 编排：模型调用分为骨架、完整方案、质检、修订四个环节；修订后质检提醒不减少时保留原方案。详细提示词见 `源码/app/js/core/agentPrompts.js`，编排逻辑见 `源码/app/js/core/agent.js`。

安全说明：

- Key 只保存在本机 `state.json`，不会上传到本项目的任何服务器。
- 桌面端通过壳层代理请求，避免浏览器 CORS 限制；代理不会打印 Key。
- 演示控制台使用独立数据目录，如需在演示中使用模型，请在演示控制台自己的设置页配置 Key。
- 浏览器预览直接 `fetch`，跨域失败时会提示使用桌面端。

## 5. 学生模式

在「设置 → 使用身份」切换到学生，进入原有的学习诊断流程：

1. 工作台输入概念问题，或选择示例主题。
2. 诊断：展开前置假设 → 第 2 层确认 → 两道短测 → 疑似断点。
3. 学习路径：三步讲解、微练习、完成标记。
4. 复测：两道不同的题，显示首测/复测事实对照。
5. 知识图谱、探索记录、导出记录。

学生模式与教师模式的数据共用同一个 `state.json`，但页面与会话互不干扰。

## 6. 演示控制台

`智析AI-演示控制台.exe` 当前内置 9 幕**学习诊断演示**，适合快速展示学生对概念断点的诊断与复测闭环：

1. 提出一个概念问题
2. 展开前置假设
3. 在第 2 层停一下
4. 两道短测确认
5. 生成可执行路径
6. 完成三步并复测
7. 人工覆写与重算
8. 教师看见共性断点
9. 收尾

控制条：上一幕 / 播放-暂停 / 下一幕、进度点、速度、重置、回封面。
原生菜单：文件（载入演示脚本 / 重新载入 / 打开脚本目录）、演示、帮助。
键盘：→ 下一幕，← 上一幕，Space 播放/暂停，Esc 回封面。

脚本自动化：

```powershell
发布\智析AI-演示控制台.exe --script="发布\演示脚本\3分钟演示.json" --autoplay
```

脚本格式与 action 列表见 [演示脚本说明.md](演示脚本说明.md)。

说明：教师工作台的完整演示可直接在正式客户端中手动走一遍；教师版自动脚本列为下一阶段增量。

## 8. 数据与隐私

所有记录只保存在本机，不上传。

- 正式客户端：
  - 状态（会话、方案、资料、设置、Key）：`%APPDATA%\ZhixiAI\state.json`
  - 窗口位置：`%APPDATA%\ZhixiAI\window.json`
  - 导出：`%USERPROFILE%\Documents\智析AI\导出\`
  - WebView2 缓存：`%LOCALAPPDATA%\ZhixiAI\WebView2\`
- 演示控制台：
  - `%APPDATA%\ZhixiAI-Demo\`
  - `%LOCALAPPDATA%\ZhixiAI-Demo\WebView2\`

设置 → 数据管理可查看存储位置、导出/导入 JSON、清空全部记录。

## 9. 数据与能力边界

- 教师侧当前内置 6 个教学场景（3 个 K12 + 3 个大学）；教材、课标/大纲、解读、校本资料均为项目自建知识库内容，来源标注到章节/课标条目层级。
- 班级、样本量、断点比例为示例数据，不代表真实学校或真实班级。
- 「自动全平台搜索」的检索阶段已建模为「资料检索 + 资料库」，当前使用内置资料与用户上传文本；接入外部搜索服务是下一阶段的 provider 集成点，本版本不伪造搜索结果。
- 未配置 API Key 时使用本地知识引擎；配置后调用 OpenAI 兼容接口，失败自动回退。
- 学生侧两题短测用于判别性确认，不等于能力测评。
- 人工覆写只改变本机状态；「重算」是本地动作。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "源码\shell\build.ps1"
```

脚本会准备 WebView2 依赖、生成两套图标、编译两次 `Program.cs`、复制前端与示例脚本，输出：

- `发布\智析AI.exe`

## 12. 技术栈

- 壳层：C# WinForms + WebView2（.NET Framework 4.6.2 兼容，csc 编译）

## 13. 常见问题

**首次启动没有工作台，只有身份选择**

这是双入口引导。选择教师或学生并完成学段/学科后才会进入工作台；可在「设置 → 使用身份 → 重新运行首次引导」再次打开。

**生成方案很慢或失败**

未配置 Key 时本地引擎通常在 1–3 秒完成；配置模型后受网络与模型速度影响。失败会自动回退本地引擎。可在「设置 → 模型连接」测试连接。

**API 测试连接失败**

检查 Base URL 是否到 `/v1`、Key 是否有效、模型名是否存在；智谱/通义等使用各自的兼容地址。浏览器预览可能受 CORS 限制，桌面端通过壳层代理。

**资料库能上传 PDF/Word 吗**

当前支持 `.txt/.md/.json` 与粘贴文本；PDF/Word 请先转为文本。后续版本会增加解析。

**想清空所有记录**

设置 → 数据管理 → 清空全部记录；或退出后删除 `%APPDATA%\ZhixiAI`（正式版）/ `%APPDATA%\ZhixiAI-Demo`（演示控制台）。

**为什么教师数据只有 3 个场景**

本版本用于验证「身份 → 资料 → 图谱 → 方案」的完整闭环；场景数据可扩展，接入外部资料与搜索服务后可按学校/教材批量建设。
