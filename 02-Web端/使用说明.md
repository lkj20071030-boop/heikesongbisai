# 智析 AI · Web 版使用说明

## 启动

1. 确认已安装 Node.js 20 或更高版本（命令行执行 `node -v`）。
2. 双击 `启动Web版.cmd`。
3. 浏览器打开 `http://127.0.0.1:8000/`（脚本会自动打开）。
4. 自动演示：`http://127.0.0.1:8000/demo.html`（9 幕，可暂停、倍速、上一幕/下一幕）。

> 本包已内置构建产物与单文件服务端，**不需要 npm install、不需要联网**。

## 页面

| 页面 | 能做什么 |
| --- | --- |
| 学习首页 | 输入一个概念问题，进入诊断 |
| 知识诊断 | 两道判别题、Agent 运行轨迹、参考资料 |
| 知识图谱 | 前置关系图、节点讲解、人工修正 |
| 学习路径 | 三步路径、完成标记、迁移复测 |
| 函数绘图 | 输入表达式出图；确定性工具调用，不消耗模型 |
| 我的收藏 / 探索记录 | 收藏、搜索、导出 Markdown |
| 偏好与连接 | 外观、推断节奏、备份导入导出、后端健康检查 |

## 内置主题

- 基尔霍夫电压定律
- 用导数判断函数单调性
- 牛顿第二定律

未知主题返回 422；这是演示范围，不代表产品只能做这三题。

## 可选：接入模型

不配置模型也能完整演示（本地知识引擎 + 七环节规则降级）。需要真实模型时：

1. 复制 `server\.env.example` 为 `server\.env`。
2. 填写 `LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY`，并设 `AGENT_ENABLED=true`。
3. 重启 `启动Web版.cmd`。
4. 首页页脚会显示"结果来自已配置后端"。

任一环节模型失败会自动回退本地规则，业务接口不报错；Agent 轨迹会标记"已回退"。

## 数据位置

- 会话：`server\.data\sessions.json`（仅服务端，含题目答案，不返回前端）
- 浏览器：localStorage（学习记录、收藏、偏好、连接配置）
- 清空浏览器记录不会删除服务端会话；删除 `server\.data` 即重置演示数据。

## 接口（/api/v1）

- `GET /health`
- `GET /agent/status`
- `POST /diagnose/start` / `submit` / `retest`
- `POST /learn/explain`
- `GET /graph/:sessionId` / `sources/:sessionId`
- `POST /chat`（未配置模型时 503）
- `GET /tools`
- `POST /tools/function.plot/invoke`

完整契约见同目录 `接口说明.md`。
