# 智析 AI · 已接入 app 资料引擎

本目录已集成本地 Node API 服务。原 app 目录未修改。

## 使用

双击「启动前后端.cmd」，或者在本目录依次执行：

```cmd
npm.cmd ci
npm.cmd run build
npm.cmd start
```

然后访问 http://127.0.0.1:8000/ 。首次安装需联网，后续本地资料模式不调用外部模型。

支持基尔霍夫电压定律、导数与单调性、牛顿第二定律。默认前端走 /api/v1 真实 HTTP 接口。

已接入分环节学习诊断 Agent（意图 → 短测 → 评分 → 路径 → 讲解 → 复测 → 答疑）：每个环节有独立提示词、JSON 校验、修复重试和本地降级；配置 OpenAI 兼容接口后由模型编排，未配置或调用失败时自动回退本地规则。详细机制见「前后端接入说明.md」。

## 自动演示

启动服务后访问 http://127.0.0.1:8000/demo.html。这是独立的 9 幕自动演示页，用同源 iframe 驱动真实应用，带封面、字幕、聚光灯、播放/暂停/上一幕/下一幕/重置与倍速控制。演示桥 `window.ZhixiDemo` 只暴露有限动作，不修改主流程。也可从首页帮助弹窗的「自动演示」入口打开。
