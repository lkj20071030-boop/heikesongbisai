# 设置功能保留说明

已更新：08-Web版。桌面版仍在 05-Windows客户端，未被修改。

## 已接入 Web 版的四个分区

- 外观：亮色、暗色、减少动效，立即应用并存储在浏览器中。首次加载读取本机主题，避免亮色闪烁；系统减少动态效果偏好也会抑制动画和展示等待。
- 推断节奏：慢速、标准、快速、立即。收到服务端数据后分别展示「匹配课程资料 → 整理前置图谱 → 准备短测」。节奏只控制展示，不改变评分，也不跳过网络请求。减少动效时不额外等待。
- 恢复默认：恢复亮色、标准节奏及完整动效，不删除记录或改变连接配置。
- 数据管理：查看浏览器存储位置和记录数量，最多保留 50 条。导出 JSON、选择文件后校验并确认恢复，清空前二次确认。导入失败不会替换当前数据。
- 关于：实际 Web 技术栈、版本 0.3.0、资料范围、浏览器和服务端数据位置、外部模型调用边界。

## 使用

双击 github-pages-ready/启动前后端.cmd，打开命令窗口显示的本机地址（默认 http://127.0.0.1:8000/），进入「偏好与连接」并向下滚动即可看到四个分区。已运行的服务可刷新页面加载新构建；若仍显示旧版请强制刷新。

## 数据边界

外观与节奏设置：localStorage 的 zhixi-preferences。
备份格式：zhixi-web-backup，version 1，最大 5 MB。备份只包含学习记录、收藏、学习档案及外观节奏，不含后端连接配置、环境变量或模型密钥。恢复只支持本 Web 版格式，不将桌面 WebView2 的状态 JSON 当作兼容备份。
「清空浏览器记录」仅清除该站点的学习记录、路径进度与收藏；server/.data/sessions.json 中的后端诊断会话不受影响。原桌面应用本机目录与记录不受影响。
Web 浏览器不能直接打开任意桌面数据文件夹，因此此处显示真实的存储方式和服务端相对路径，不提供无效的「打开本机目录」按钮。
